# B站当前分P下载工具

Windows 离线工具，用于下载当前打开的 B 站视频分P。

## 功能

- 识别当前打开的视频及当前分P
- 使用浏览器当前登录状态获取账号有权访问的画质
- 支持选择清晰度和高帧率版本
- 自动下载并合并视频与音频
- 支持指定开始、结束时间
- 使用原始码流切割，不重新编码
- 支持 MP4、MKV 视频的独立无损切割工具

## 系统要求

- Windows 10/11 64 位
- Google Chrome
- 无需另外安装 FFmpeg
- 无需另外安装 .NET

## 下载

请前往右侧的 **Releases** 页面下载最新版：

`B站当前分P下载工具-v1.3.0-Windows-x64.zip`

不要点击仓库上方的“Download ZIP”，那里不是软件安装包。

## 安装方法

1. 下载并解压 ZIP，不能直接在压缩包内运行。
2. 打开 Chrome，在地址栏输入：

   `chrome://extensions/`

3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压目录中的 `extension` 文件夹。
6. 复制扩展卡片上显示的 32 位扩展 ID。
7. 双击运行 `安装本地助手.bat`。
8. 粘贴扩展 ID 并按回车。
9. 关闭并重新打开扩展弹窗。

可以运行 `启动检查.bat` 检查本地助手及 FFmpeg 是否完整。

## 使用方法

1. 使用 Chrome 登录 B 站。
2. 打开需要下载的视频，并切换到目标分P。
3. 点击浏览器工具栏中的扩展图标。
4. 选择清晰度。
5. 如需切割，填写开始和结束时间，例如：

   `1h20m30s`

6. 不填写时间则下载完整视频。
7. 点击“开始下载”。

最终文件默认保存在解压目录下的 `downloads` 文件夹。

## 注意事项

- 原码流切割不会重新编码，因此画质和音质不会下降。
- 由于关键帧限制，切割边界可能存在数秒偏差。
- 大会员、充电内容及其他受限内容能否访问，取决于当前登录账号本身是否具有合法访问权限。
